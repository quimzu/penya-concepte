# Penya · Concepte de web

Concepte de disseny **no oficial** per a un nou web del Club Joventut Badalona, fet per [Boira.studio](https://boira.studio) des de la grada.

No és el web oficial del club. Les fotos, l'escut i les marques pertanyen als seus titulars i s'utilitzen només per il·lustrar la proposta.

## Què hi ha

- Capçalera de matchday amb compte enrere per al pròxim partit a casa.
- Pròxims partits amb selector d'equip: primer equip, femení, U22 i Menarini BCR.
- "4 equips, un sol sentiment" i el relat de la cantera.
- Model 3D interactiu del Palau Olímpic de Badalona (three.js).
- Bloc de socis amb l'opció d'aficionat solidari per a penyistes que viuen lluny.
- Botiga integrada al mateix web.

## Com veure-ho

És una pàgina estàtica: obre `index.html` o publica la carpeta amb GitHub Pages.
